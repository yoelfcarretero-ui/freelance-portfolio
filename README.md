# Yoel Carretero, freelance developer

I'm a software development student from Spain. I help founders and small businesses with three things: getting apps built with AI tools working in production, automating repetitive work, and adding AI assistants that actually know their business.

This repository is my public portfolio. Each project below is a complete, working demo with its source code, tests and documentation, built the same way I would build it for a client.

## Services

- **Fix, finish and deploy apps built with Lovable, Bolt or Base44.** Auth, database, payments, broken deploys and features the AI could not finish.
- **Security review for Supabase apps.** Row Level Security, exposed keys, storage and auth settings, with a clear report and the fixes applied.
- **n8n automations with AI.** Connect the tools a business already uses and let AI handle the repetitive parts.
- **AI chatbots trained on your documents.** A website assistant that answers customers from your own information and hands off to you when it should.
